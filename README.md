# AdmiralGame - Тактична гра

## Опис гри

AdmiralGame - це тактична стратегічна гра для двох гравців, де кожен гравець розміщує свої військові фішки на полі 10x10 і веде битви по черзі.

### Правила гри

1. **Фаза розміщення:**
   - Гравці по черзі розміщують свої фішки на полі
   - Кожен гравець має: 2 піхотинці, 1 танк, 1 артилерію, 1 командира
   - Перші 2 рядки належать Гравцю 1, останні 2 рядки - Гравцю 2

2. **Фаза битви:**
   - Гравці ходять по черзі, переміщуючи фішки на 1 клітинку
   - Можна атакувати ворожі фішки переміщенням на їхню клітинку
   - Кожен тип фішки має свою силу:
     - Піхотинець: 2
     - Танк: 4
     - Артилерія: 3
     - Командир: 2

3. **Перемога:**
   - Гравець, який знищив усі фішки супротивника, перемагає
   - Гра завершується автоматично коли один з гравців втрачає всі фішки

### Керування

- **Камера:**
  - **Обертання:** натиснути середню кнопку миші (колесо) + рух миші
  - **Зум:** крутіння колеса миші (змінює поле зору камери)

- **Фішки:**
  - **Вибір фішки:** клік лівою кнопкою миші на фішку поточного гравця
  - **Переміщення:** після вибору фішки клікнути на зелену клітинку (сусідню вільну)
  - **Атака:** клікнути на зелену клітинку з ворожою фішкою

- **Інтерфейс:**
  - **Ліва панель:** інформація Гравця 1
  - **Права панель:** інформація Гравця 2
  - **Центр:** поточний хід та кнопки керування
  - **Кнопка "Завершити розміщення":** завершує фазу розміщення для поточного гравця
  - **Кнопка "Завершити хід":** завершує хід поточного гравця в фазі битви
  - **Кнопка "Почати знову":** починає нову гру

## Як запустити сервер

### Варіант 1: Python (рекомендовано)

1. **Встановіть Python** (якщо не встановлено):
   ```
   # Завантажте з https://www.python.org/downloads/
   # або для Windows: завантажте установник та запустіть
   ```

2. **Запустіть сервер:**
   ```
   # Відкрийте командний рядок (cmd) в папці гри
   cd c:\dev\admiralgame
   python -m http.server 8000
   ```

3. **Відкрийте гру:**
   ```
   # В браузері перейдіть на:
   http://localhost:8000
   ```

### Варіант 2: Node.js

1. **Встановіть Node.js** (якщо не встановлено):
   ```
   # Завантажте з https://nodejs.org/
   ```

2. **Встановіть http-server:**
   ```
   npm install -g http-server
   ```

3. **Запустіть сервер:**
   ```
   cd c:\dev\admiralgame
   http-server -p 8000
   ```

4. **Відкрийте гру:**
   ```
   http://localhost:8000
   ```

### Варіант 3: VS Code Live Server

1. **Встановіть розширення "Live Server" у VS Code**
2. **Клікніть правою кнопкою миші на файлі `index.html`**
3. **Оберіть "Open with Live Server"**

### Варіант 4: Render.com

Цей проєкт потрібно деплоїти на Render як **Static Site**, а не як **Web Service**.

1. Підключіть GitHub-репозиторій у Render
2. Оберіть **New +** -> **Static Site**
3. Якщо Render читає конфігурацію з репозиторію, він підхопить файл `render.yaml`
4. Якщо заповнюєте вручну:
   - **Build Command:** залишити порожнім
   - **Publish Directory:** `.`
5. Після деплою відкрийте URL сайту

Якщо ви раніше створили **Web Service**, Render міг показувати помилки на кшталт відсутності `npm`, `package.json`, `start command` або порту. Для цього проєкту це нормальна ознака неправильного типу сервісу.

## Як вимкнути сервер

### Для Python сервера:

1. **В вікні командного рядка натисніть `Ctrl + C`**
2. Або просто закрийте вікно командного рядка

### Для Node.js сервера:

1. **В вікні терміналу натисніть `Ctrl + C`**
2. Або закрийте вікно терміналу

### Для VS Code Live Server:

1. **Натисніть `Ctrl + Shift + P`**
2. **Введіть "Live Server: Stop Live Server"**
3. Або клікніть на іконку Live Server в правому нижньому куті та оберіть "Stop"

## Вимоги до системи

- **Браузер:** Chrome, Firefox, Safari, Edge (підтримка WebGL)
- **Операційна система:** Windows 10/11, macOS, Linux
- **Пам'ять:** мінімум 2GB RAM
- **Відеокарта:** підтримка WebGL

## Вирішення проблем

### Проблема: "Сервер не запускається"
- Перевірте чи порт 8000 вільний
- Спробуйте інший порт: `python -m http.server 8080`
- Перевірте чи файли не заблоковані антивірусом

### Проблема: "Гра не завантажується"
- Очистіть кеш браузера (Ctrl + Shift + Delete)
- Спробуйте інший браузер
- Перевірте чи підтримується WebGL

### Проблема: "Камера не працює"
- Перевірте чи не заблоковано мишу
- Спробуйте оновити сторінку (F5)
