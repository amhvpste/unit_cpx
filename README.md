# units-cpx

## Опис

https://unit-cpx-1.onrender.com/

`units-cpx` — це браузерний тактичний прототип на `Three.js` для двох гравців. Гра поєднує:

- магазин юнітів перед розстановкою
- наземний і повітряний шари
- покрокове управління
- автоматичне розв'язання зіткнень
- туман війни під час фази ходів
- вбудовану довідку по юнітах для методистів і тестування

## Поточні механіки

### Фази гри

1. Магазин
2. Розстановка
3. Битва
4. Завершення гри

### Шари поля

- `земля` — наземні підрозділи
- `повітря` — БПЛА та інші повітряні об'єкти

У фазі бою є кнопка перемикання активного шару. Повітряні клітинки збігаються з наземними координатами, тому повітряний юніт може працювати над тією ж самою клітинкою, що й наземна ціль.

### Туман війни

Туман війни працює тільки у фазі ходів.

- під час розстановки туману немає
- видимість рахується спільно від усіх юнітів поточного гравця
- звичайні наземні юніти бачать на `1` клітинку
- `розвідник` бачить на `3`
- усі дрони зараз бачать на `3`

### Бойові правила

- ближній бій відбувається при контакті
- `артилерія` атакує найближчу ціль у своєму шарі на дистанції до `3`
- `снайпер` атакує найближчу ціль на дистанції до `2`
- `БПЛА камікадзе` знищує наземну ціль, якщо опиняється над нею в тій самій клітинці

## Довідка в грі

У центрі інтерфейсу є кнопка `Довідка`.

Вона відкриває окрему прокручувану сторінку з:

- переліком усіх юнітів
- тактичним значком кожного юніта
- візуальною моделькою
- параметрами
- коротким описом
- приміткою для методистів щодо поточного стану позначень

Це зроблено спеціально для перевірки ігрової мови, значків і відповідності методичним вимогам.

## Керування

### Камера

- обертання: середня кнопка миші + рух
- зум: колесо миші

### Інтерфейс

- `Завершити хід` / `Завершити розміщення`
- `Шар: земля` / `Шар: повітря`
- `Довідка`
- `Почати знову`

### Взаємодія

- клік по власному юніту — вибір
- клік по клітинці — рух або розстановка
- клік по ворожому юніту — показ інформації, якщо він видимий

## Важлива примітка щодо значків

Поточні тактичні значки стилізовані під сучасну мову `NATO/AFU`, але ще не є фінальною методично вивіреною версією. Саме тому в гру додана окрема сторінка довідки для рецензування.

## Деплой на Render

Проєкт потрібно деплоїти як `Static Site`.

Якщо налаштовувати вручну:

- `Build Command` — порожньо
- `Publish Directory` — `.`

Після нового пушу:

1. відкрити сервіс у Render
2. натиснути `Manual Deploy`
3. вибрати `Deploy latest commit`
4. після деплою оновити сторінку через `Ctrl + F5`
